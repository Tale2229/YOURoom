# YouRoom

北邮空闲教室自习筛选工具，原生 Android / Kotlin / Jetpack Compose。

已接入西土城（`campusId=01`）与沙河（`campusId=04`）的空闲教室查询，复用现有教务登录协议。不需要微信、自建后端或浏览器 Cookie。沙河参数来自[学校发布的课堂页面代码](https://jwglweixin.bupt.edu.cn/sjd/static/js/23.3486c5a076a22b47d095.1741852738390.js)，真实账号列表比对仍须在手机上验收。

## 1.7.1 教室时段条长按查看

- 教室条目上方的名称、属性和备注区域响应左滑四按钮；下方时段条及上下留白用于查看节次时间，两个手势区域不重叠。
- 在时段条处停留约 250ms 后显示简短时间，例如 `6 · 13:00–13:45`。轻点或等待期间明显移动不显示提示，竖向拖动仍正常滚动列表；进入查看后锁定当前教室，左右或上下移动均按横坐标切换节次，松手恢复滚动。
- 当前小条上移 4dp，时间浮层显示在其上方；不增加条目高度，不改变布局位置或空闲颜色。条间空隙归到最近的节次，超出左右边界时显示首 / 末节；灰色小条也可查看，但不表示空闲。
- 时间来自当前校区的真实节次响应，不硬编码；松手、取消、多指、切校区或更新响应后关闭。查看不改筛选、收藏、排除或其他标记，不启动查询；读屏 / 键盘也能查看，非触控提示约 2 秒后消失。展开四按钮时不同时开启时段查看。

## 1.7 左滑教室操作（历史）

- 删除整屏教室详情。在“找教室”的教室条目上左滑，依次显示收藏、标签、斜笔备注、排除四个图标按钮；右滑或点击条目可收起，最多展开一条。普通点击条目不再打开详情，竖向手势仍滚动列表，时段拖选与顶栏切校区不受影响。
- 收藏沿用原有数据与星号状态，仅展开时显示星号；平时以校区同色系的加深背景区分收藏教室，适配暗色模式。
- 标签使用独立小弹窗，沿用筛选词条的外观与“＋”添加入口，但没有教学楼、收藏项、全局删除或排序操作。勾选即时更新教室标记，新建词条同时标记本教室；“重置”仅清除标签，不改变收藏、排除、备注或搜索条件。
- 斜笔打开独立备注输入弹窗，逐次输入即时保存，保留空格和 500 字限制；“清空”仅清除备注。没有另设保存按钮，不在卡片下展开。
- 排除按钮区分未排除 / 已排除状态。不选自习时段时仍展示被排除的教室，名称后显示圆圈叉号，已收藏的继续置顶并保留加深背景；选中任意节次后才隐藏被排除的教室。屏蔽 / 取消屏蔽始终修改同一排除标记，不随节次改变；楼宇、搜索及其他个人词条筛选仍生效。也可在“个人偏好”取消排除。自习规划继续避开排除教室，规划路线及个人偏好的点击入口为紧凑的四操作弹窗。

## 1.6 自习规划（历史）

- 底部新增“自习规划”，位于“找教室”和“个人偏好”之间。输入今日起止时间，按需启用时间调整、午休推测并选择出发教学楼；规划输入独立于原有节次 / 搜索 / 筛选，切换板块保留输入。
- 同一个时间前向动态规划器评估完整路线，再在候选时间中选择推荐、原时段及少搬动方案（重复方案合并）。候选时间按 5 分钟步进，补充课表边界与整体平移；整体平移最多 15 分钟，裁剪、搬动和等候合计最多损失 20 分钟（可全部裁在同一端），最多换教室 2 次。
- 可解释的总代价：`3 × 自习损失 + 起止偏移之和 + 20 × 换房次数 + 12 × 换楼次数 + 2 ×（途中步行 + 开始前抵达耗时）− 收藏自习分钟`。同等覆盖和时间下，额外十分钟收藏不足以抵消一次换房；自定义词条不评分，个人排除是硬限制。
- 保留到达时间、累计损失和换房次数等状态；针对综合代价及少搬动分别保留有效前缀，不能由较早的局部选择抹掉后续可行性。搬动 / 等候是独立时间段，不与教室自习重叠；可点击自习段打开原有教室详情。
- 根据校区响应生成空闲区间，不穿越未列空闲的教学节次。相邻两节都空闲时，普通课间（≤20 分钟）可推测衔接；更长休息时段必须主动允许（最多 90 分钟），结果单独显示推测分钟。缺失节次不补造；只能使用当前校区当日快照，真实规划不能推荐已经过去的开始时间，演示允许查看全天。真实出发楼的预计抵达时间必须在首段自习前；已生成计划在同日回看时不会仅因时钟推进被取消。
- 西土城“未来学习大楼”按用户确认映射为主楼；教学楼 1–4 与主楼使用初始估算步行表，沙河两楼采用固定估算。楼层、同层编号距离、上下楼与收拾时间共同计入搬动；无法识别的名称采用保守估算。所有移动耗时都是未实测的估计，不是地图导航或实时空座保证。
- 在后台计算，离开页面或更新时间 / 校区 / 快照会取消旧任务，旧结果不能覆盖新输入。没有改动登录协议、数据库 schema 2 或运行依赖，保留已有收藏、备注与之前尚未提交的 1.5.3 改动。

## 架构

```text
Compose 页面
    ↓ 用户操作 / ↑ StateFlow 状态
YouRoomViewModel
    ├─ ClassroomFilter：纯 Kotlin 筛选、交集与排序
    ├─ SettingsStore：DataStore 保存筛选偏好
    └─ ClassroomRepository
         ├─ SchoolApi：OkHttp / HTTPS / Token，无 Cookie
         ├─ YouRoomDao：Room 保存快照、收藏、标签和备注
         └─ SecureSessionStore：Android Keystore + AES-GCM
```

使用单 `app` 模块、手动依赖注入和单向状态流，避免为首版引入多模块或远程服务的额外维护成本。

主要文件位于 `app/src/main/java/com/example/youroom/`：

| 位置 | 职责 |
| --- | --- |
| `data/SchoolApi.kt` | 登录、查询及 HTTP / 业务错误映射 |
| `data/LegacyPasswordEncoder.kt` | 兼容学校现有密码编码协议 |
| `data/SchoolJson.kt` | 严格解析和验证返回数据 |
| `data/ClassroomRepository.kt` | 会话、网络、缓存和跨午夜校验 |
| `data/local/` | Room、DataStore、Keystore |
| `domain/` | 数据模型、跨节次交集、个人偏好筛选 |
| `ui/YouRoomViewModel.kt` | 页面状态、登录与刷新、演示隔离 |
| `ui/` | 登录、找教室、自习规划、个人偏好、左滑操作与标签 / 备注弹窗 |

数据库 schema 已导出到 `app/schemas/`。以后改变表结构时应增加数据库版本并提供迁移，不应通过破坏性迁移删除用户收藏。

## 学校接口约定

基础地址：`https://jwglweixin.bupt.edu.cn/bjyddx/`。

| 操作 | 方法 / 路径 | 参数或认证 |
| --- | --- | --- |
| 登录 | `POST /login`，空请求体 | Query：`userNo`、编码后的 `pwd`、`encode=1`、空 `captchaData`、空 `codeVal` |
| 教室 | `POST /todayClassrooms`，空请求体 | Query：`campusId=01`（西土城）或 `04`（沙河）；请求头 `Token` |

登录成功读取 `data.token`；查询成功需要业务码 `code=1`。学校会用 **HTTP 500 + 业务码 401** 表示未授权，不能把所有 HTTP 500 都当成 Token 失效。

响应行包含 `NODENAME`、`NODETIME` 和 `CLASSROOMS`。解析器保留 `未来学习大楼-202-203` 等复合教室编号，只将末尾数字括号解析为容量。

接口没有日期字段。App 保存的是请求发生时的北京时间日期与获取时间，**不能据此证明学校已经刷新了当天数据**，也不会把缓存重新标记成今天。一次请求跨越北京时间午夜会被拒绝缓存，要求重新刷新。

`Origin` / `Referer` 沿用此前成功请求的值，其必要性未单独验证。如果学校增加验证码、调整认证或更改字段，首版会提示错误，不尝试绕过。

## 安全边界

- 不在源码、配置或测试中保存真实账号、密码、Token、Cookie。
- 密码仅参与本次登录，不写入 SharedPreferences、数据库或页面恢复状态；提交后清空输入框。
- 学校前端的固定 AES-ECB 密码编码只是协议兼容，**不是安全的密码存储方案**；通信安全依赖正常校验证书的 HTTPS。
- 登录协议把编码密码放在 URL Query 中。因此不要添加网络日志拦截器，也不要分享完整登录 URL、HAR 或登录响应。
- Token 用 Android Keystore 密钥进行 AES-GCM 加密，密文存入应用私有 SharedPreferences；无法解密时要求重新登录，没有明文回退。
- Token 文件从 Android 云备份和设备迁移中排除。系统备份可包含教室缓存和个人偏好；App 自身不上传这些数据到第三方服务器。
- 退出登录清除本机 Token，但保留收藏与备注；当前未调用学校的服务端 Token 撤销接口。
- 使用系统证书信任配置，不允许明文 HTTP，不自动追随携带凭据的重定向。
