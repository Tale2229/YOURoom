## 资源与显示

### 1.37.4：修复头像右侧细白边

2026-10-21，逐张检查十二张正式 WebP：全部为不透明图片，右侧没有突变白色像素列。本次不重新生图、不改 PNG 或 WebP，也不改 HTML。

模拟器在 2.625× 等非整数屏幕密度下复现了细缝：75dp 位图取整为整数像素，边框开口仍按浮点 10dp 内缩，另外头像在大 Canvas 中直接居中，与边框先布局再内部居中的取整路径不同，导致右侧露出页面底色，浅色页面看起来像白边。

边框开口、静态头像和磁吸条带共用整数像素几何，先定位 95dp 边框，再在其中居中 75dp 头像。保留原图、配色、圆角、120dp 中心间距、磁吸阈值和换色时序；只调整不足一个像素的显示对齐。新增几何单元测试与五种密度、十二主题明暗页的边缘像素回归测试。

验证：先在旧实现中复现边缘断言失败（2.625×，右侧像素平均通道误差约 0.302）；修复后 586 项单元测试、18 项专项设备测试通过。边缘回归覆盖 2 / 2.625 / 2.75 / 3 / 3.5×，以及十二主题在两种分数密度、明暗页的 48 次边缘比对；原有双校区 / 明暗模式 48 次头像比对与磁吸、惯性、边框留色、波浪时序回归通过。原图和 WebP 像素校验全部通过，已查看修复前后原生截图；普通 / 隔离构建及正式包名版本 `com.example.youroom`、`1.37.4 / 113` 核对通过。仅安装自建模拟器，未操作用户手机，未运行全量设备测试或 Lint，未提交或推送。

- 正式资源在 `app/src/main/res/drawable-nodpi/theme_avatar_<ID>.webp`，每张 384×384；十二张共 1,390,852 字节，约 1.33 MiB。
- 从定稿原图高质量缩小后无损编码为 WebP，完整保留构图，不增加裁切、着色或滤镜。原图与所有历史稿仍在本地 `docs/colors/<主题>/`，不被覆盖。该设计目录沿用既有 Git 忽略规则；正式资源、映射及说明可随项目正常跟踪。
- 维持 75dp 头像与 10dp 圆角外框。两校区、明暗模式共用同一张定稿图；1.36.5 采用[1.25× 间距与阈值磁吸](theme-avatar-frames.md)，中心间距为 120dp，实际吸附距离保持不变。全带在吸附范围内居中锁定、越过阈值才释放。空档保留上次吸附颜色，捕获新头像再换色，整页按原流程换色。
- [资源映射](../app/src/main/java/com/example/youroom/ui/ThemeAvatarAssets.kt)集中管理十二张图。[头像组件](../app/src/main/java/com/example/youroom/ui/ThemeImpression.kt)解码并缓存后复用于中心头像、滑动条带、箭头切换与整页换色过渡，避免逐帧解码。
