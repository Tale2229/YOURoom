# 头像边框与磁吸预览

## 1.37.4：边框与头像像素对齐

2026-10-21，统一边框内沿、静态头像与吸附条带的整数像素位置，修复非整数屏幕密度及奇数布局尺寸下右侧露出页面底色的细缝。仍为 75dp 头像 / 95dp 边框，原图与颜色不改，120dp 中心间距、整条带受力和磁吸时序保持原值。细节与验证见[头像记录](theme-avatars.md)。

## 已确认的交互基线

版本 1.36.5 / 108。正式应用采用 96dp × 1.25 = 120dp 头像中心间距，替代此前的 144dp。头像仍为 75dp，边框仍为 95dp / 10dp 厚；显示范围、配色、缩放和透明度规则不变。边框位于头像上层，只在捕获新头像时换色，空档保留原色。吸附的实际距离不随间距改变。本次按用户要求只改正式应用，HTML 不变。

## 当前：原单色边框

- 直接使用各主题现有 `impressionFrame` 色值及原有透明度；不取样头像、不生成渐变、不额外降低深色模式透明度。
- 颜色依据待预览主题解析，而不是已应用的页面主题，继续保留预览先变色、180ms 平滑过渡和快速连续操作中断。
- 无捕获时保持上一次吸附的颜色，不增加中性、透明或灰色的中间状态。内部始终镂空，仍露出头像 / 真实页面背景。
- 边框在头像上方绘制。最新 HTML 默认「原单色」，历史渐变只作对照；整条带受力现已同步到正式应用。

## 色彩延展（历史试验，已撤回）

- 保持 75dp 头像、95dp 外框、10dp 厚度及 14dp 外圆角。
- 从定稿头像四边各取三处区域，平滑混合成有方向的色彩场；轻微降低饱和度，仅延展色彩，不复制图案细节。蒙德里安过滤接近黑色的取样，避免黑线扩散为灰边。
- 沿圆角向外渐淡，内侧约 40%、外侧约 10% 不透明度；深色模式乘以 0.7，与已确认预览一致。取样和渐变位图随头像缓存，不在拖动时重新分析或生成。
- 切换目标采用 180ms 交叉淡化。连续操作中冻结当前混合结果再接续，避免闪回旧颜色。半透明层单独混合，不与页面背景做加色。

## 与整页主题解耦

- 箭头点击：依据待预览主题立即更新边框，不等待保存、320ms 防抖或整页波浪。
- 滑动：依据磁吸捕获的头像更新边框；只是浏览，不提前写入设置。
- 无捕获：保留上一次捕获的主题颜色，捕获另一个头像后才过渡到新色；不采用任何中间状态。
- 松手：已锁住时抑制甩动速度，回到锁定项；已挣脱时保留原生惯性 / 最终居中。之后仍是 800ms 停留 → 160ms 箭头恢复 → 整页波浪，没有额外等待。
- 禁用、离开页面、后台或切换校区时沿用原有取消 / 保存边界，不把未确认的磁吸状态带到另一个校区。

## 磁吸手感

[ThemeBeltMagnet.kt](../app/src/main/java/com/example/youroom/ui/ThemeBeltMagnet.kt)以 120dp 条带步距为单位，阈值先定义为物理 dp 再换算成步数：

- 使用原始滚动坐标判断阈值，不用已被吸住的视觉坐标判断，防止锁定后无法挣脱。
- 距中心不超过 23.04dp（0.192 步）时，直接把整条带的视觉目标设为对应头像的精确中心。
- 已锁住时，原始拖动距离不超过 36.48dp（0.304 步），视觉目标始终保持不动；超过后才释放。释放后须回到 23.04dp 内才重新捕获，避免阈值附近抖动。与原 96dp / 144dp 版本的实际阈值相同。
- 头像不再只是减速靠近：锁定时准确居中，进入 / 挣脱使用快速临界阻尼弹簧衔接。全带只有一个视觉坐标，所有中心间距固定 120dp，远端缩放和透明度继续依据该坐标计算。
- 未挣脱便松手时，不允许短促甩动靠惯性切走头像；已挣脱的滑动保留原生惯性、跨多主题快速浏览、中断和最终居中。箭头操作不受拖动阈值限制。

实现位于 [ThemeAvatarFrame.kt](../app/src/main/java/com/example/youroom/ui/ThemeAvatarFrame.kt) 和 [ThemeImpression.kt](../app/src/main/java/com/example/youroom/ui/ThemeImpression.kt)。当前测试检查原单色 / 原透明度、双校区 / 明暗预览、空档保持颜色、前景边框遮挡穿行头像、共享位移与固定间距；捕获滞回和交互时序保留。以下 1.36.1 的中性边框记录仅为历史状态。
