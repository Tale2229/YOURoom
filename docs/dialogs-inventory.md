## 如何使用

- 默认显示马蒂斯浅色下的全部弹窗，可切换 12 主题、浅 / 深色、校区、字号，按功能、窗口类型、标题或源文件名筛选。
- 每个样例有唯一编号、入口、导航层级、源码和状态说明；放大后可切换前后样例，或沿“上层 / 相关状态”查看。
- 点击确认弹窗的放大预览会显示灰色蒙版下的上层窗口，方便后续同时调整两层视觉。导航层级不等于同时叠加的物理窗口数，编辑器等替换式窗口不会被全部堆叠。
- 标签切换、备注输入 / 计数、偏好选项、时段添加、章节选择、小猪动画可以轻量操作。状态选择器用于稳定查看报错，不依赖当天时间、网络或真实账号。
- 身份校验、清除缓存、删除、退出和外部链接均是安全的样式预览；不发 HTTP 请求，不使用 localStorage，不向正式应用写入任何信息。建议只填写虚构内容。

## 主要层级关系

```text
筛选教室 → 编辑词条 → 删除词条确认
教室标签 → 编辑词条 → 同一个删除确认
教室标记 → 教室操作 → 教室标签 / 备注（替换窗口）
        └→ 清除该教室标记确认
规划偏好 → 常用组合 → 新建 / 修改（替换管理窗口）
                  └→ 删除组合确认（叠加）
长按加号 → 导入组合 → 替换当前时段确认
                  └→ 常用组合管理 → 编辑器
时段菜单 → 保存组合（预填所有已添加时段）
清除缓存 → 全量删除确认 → 身份校验 → 校验中 → 清除中 → 已交系统
指引总目录 → 四章的小节目录（替换目录内容）
```

## 特殊边界

- 只收录源代码中真实存在的窗口。时段菜单的正式调用提供三个按钮；未另造一个没有保存按钮的“二按钮弹窗”。编辑器中的时段点击直接回填滚轮，也没有额外操作弹窗。
- “默认偏好”的五项展开属于原弹窗内部状态，不算新窗口。标签、模板和导入的报错也属于原窗口内部状态，已用样例或状态选择器覆盖。
- 运行时网络错误可能有任意内容，A07 保留源码已有的代表性错误文案，不宣称穷举服务器所有错误字符串。A09 / A10 为通常很短暂的不可逆状态，预览中固定展示，绝不真正调用系统清除。
- R01 可从设置教室标记或规划结果进入；R02 / R04 也可直接从教室左滑按钮进入。Q05 在两处标签编辑共用，不重复算作两个窗口。
- A03 保留 `viewingCache` 的源码分支，即使当前登录页已不展示旧缓存入口。A04 包括演示等非正常登录状态的说明。
- 沙河教学楼来源取决于真实数据；此预览只使用仓库 `DemoData` 中的“演示楼”，不虚构真实校舍列表。教室、账号和时段都是排版样例。
- 小猪正常图取自 `app/src/main/res/raw/about_pig.svg`，眯眼沿用正式矢量的眼睛路径并内嵌；g66 水印从正式 `about_mark.xml` 的 40 条路径内嵌成 SVG，避免本地文件跨域遮罩缺失，无网页资源链接。
- 不将内联时段条样式 / 默认校区选项、规划结果抽屉、页面错误提示、系统键盘 / 自动填充或 Android 系统窗口冒充为应用弹窗。
