# 使用指引

版本：1.40.16 / 132。当前共 43 步。指引设计优先解释功能和操作，不额外强调主题波浪或其他动画。

引导框默认固定底部；第 41 步退出登录、第 42 步清除缓存例外，位于对应按钮正上方，按钮完整露出。根据高亮区剩余空间限高，框内内容可滚动，切换步骤重新从说明开头阅读；大片高亮时保留至少 128dp 的可滚动区域（仍受窗口最大高度约束），不因剩余空间不足而隐藏引导。第二步及点击设置页的导航入口阶段在底部导航上方留出开口，不覆盖导航。

## 入口与操作

### 1.40.16 手动指引、完成记录与连续布局

- 删除播放 / 暂停按钮、播放状态和自动播放计时逻辑，保留上一步 / 下一步、目录、跳过及单步“替我演示”。目录固定在底部正中；最后一步右侧改为 18dp 小叉号，仍保留 48dp 触摸区域及“完成指引”无障碍名称。
- 完成记录要求本步发生真实回调或用户主动点击“替我演示”，并满足对应操作结果。仅切换步骤、初始化示例、自动展开条目或后续步骤预置收藏，不能产生完成勾号；真实完成后撤销、返回、恢复仍保留记录。
- 第 8 / 9 步共享同一个筛选弹窗和宿主，双向切换不重挂弹窗；原入口与高亮目标保持不变。
- 第 39 步“关于”在说明框上方可用空间内底部对齐，与指引框间距约 12dp，不再贴到屏幕顶端；短屏上内容仍可滚动。仅调整练习展示，不改变正式关于页面。
- 第 41 / 42 步同时保留两个按钮的定位锚点；准备阶段关闭视觉开口时，引导框仍使用按钮位置，不先落回屏幕底部。其他步骤的位置规则不变。
- 保持 43 步、进度与数据隔离规则不变；下方旧版本章节为历史说明，播放相关记录不再代表当前行为。

### 1.40.15 跨步骤弹窗与布局准备

- 弹窗挂载同时检查当前步骤、内部入口阶段和目标窗口，不能仅依赖稍后执行的清理。修复第 9 → 10、19 → 20、25 → 26、26 → 27、38 → 39 步旧弹窗被短暂重新挂到新步骤的问题，包括新建组合、未确认的替换、期望教室，以及组合管理尚未打开 / 已打开两种情况。
- 第 23 / 24 / 25 步共用导入弹窗；第 25 步回到第 24 步只移除替换确认框，同时清空其本地待确认状态，不关闭重建导入窗口。再次点击组合仍可正常进入确认。
- 第 27 步进入时清理练习计算状态；练习生成按钮及请求回调只在“开始规划”一步允许启动，准备阶段也禁止触发。终止计算 / 查看结果所需的显式示例准备保持不变，展开方案仍沿用已有结果。
- 第 32 步说明更新为“进入设置页面，点击左右箭头或者滑动来切换配色。合适的色彩能带来愉悦、共鸣，也是一种自我表达哦”。
- 第 35 / 36 步先恢复全屏半透明灰色蒙版，在其下直接收起上一步的选项；等待布局确认及连续稳定帧后才定位并显示新开口，避免对着尚未收起的布局定位。正式页面与用户主动展开 / 收起的动画保持原样。
- 第 38 步组合管理仅供查看：所有组合的整行、间隙附近点击、垃圾桶、新建及退出按钮都不可操作，不再只保护“指引练习”一条；不影响正式组合管理。
- 保持 43 步、默认暂停、进度迁移及数据隔离规则，不操作正式账号、组合或偏好。

### 1.40.12 移除顶栏与清理练习收藏

- 删除顶部“指引练习 · 示例时间 10:00 · 不影响你的数据”提示栏，让练习页面直接占满原有可用区域。示例时钟和练习数据隔离机制不变。

- 第 9 步先高亮筛选弹窗下方加号；点击后在原步骤、原说明下开放标签编辑区，取消编辑后可再次从加号进入。

- 第 20 步点击加号触发过去时间提示后，自动衔接第 21 步及可用的“从现在起”入口，不再等待手动下一步。

- 第 27 步继续支持图钉添加 / 取消、垃圾桶清空，禁用右下角叉号 / 勾号退出按钮。
- 第 32 步选择方案后保持方案列表展开、高亮开口可用，可连续切换导向、滑动和选择其他方案，不重新计算。
- 仍为 45 步，标题、说明、完成记录、三行说明区及持续蒙版机制不变；以上规则取代下方旧版本对应规则。

- 跳转步骤时自动准备示例数据、时间、页面和弹窗。指引内的页面、练习弹窗与目录共用一个物理窗口、一个持续挂载的灰色蒙版，避免原生弹窗进出场和重复 dim 层导致明暗闪烁；正式使用中的原生弹窗不变。
- 自动准备期间封闭高亮开口并屏蔽底层点击，校区、页面、时间滚轮和条目展开直接落到所需位置；不逐个播放前置导航和滚动。目标窗口、示例时间及全部开口坐标连续两帧稳定后才开放高亮，不使用固定等待秒数。
- 用户在当前步骤中主动切换页面 / 校区、调整时间、收藏与取消等操作继续保留原有反馈；跳过和前后切换仍可用，新跳转会取消旧步骤等待，不重置本轮完成记录。

- 首次观看演示自动打开指引；首次成功登录的每个账号独立记录。记录保存在当前设备，不跨设备同步。
- 设置页在“规划偏好”和“关于”之间新增“使用指引”，可选择章节重复查看。
- 支持上一步 / 下一步、目录、跳过；无播放功能。互动步骤可手动练习，也可点“替我演示”，或直接下一步跳过。
- 不按时间自动翻页；旋转、恢复界面及后台返回保留步骤与目录状态。
- 完成或跳过后不再自动弹出。未完成的指引再次进入时提供继续或选择章节；返回键打开目录。
- 目标控件未就绪时不强行计时翻页；后台自动尝试滚动定位并重新读取布局，不展示“重新定位”按钮或等待提示，仍可下一步或跳过。重试次数有上限，目标就绪或切换步骤后取消，不重新初始化步骤或清除练习。

## 章节

共 43 个小步骤；其中 10 步提供“替我演示”，其余可手动操作高亮区域或阅读说明后切到下一步。

| 章节 | 展示范围 |
| --- | --- |
| 查询教室 | 底部导航、滑动切换校区、节次点击与拖选、长按时间、搜索清空、楼宇与词条筛选 |
| 管理教室 | 左滑四按钮、收藏、标签、备注、排除与恢复、设置页集中管理标记 |
| 规划自习 | 时间滚轮、添加、时段编辑 / 删除 / 保存、过去时段、从现在起、快捷时长、长按导入、替换确认、期望教室、宽松模式、生成 / 停止、其他方案 |
| 设置与帮助 | 配色条带与三角按钮、深色模式、时段条、编号、默认校区、规划偏好、组合管理、关于、重播入口、退出确认、清除全部本地数据说明 |

“清除缓存”为纯说明步骤，只解释确认、身份校验、删除范围与应用关闭，不实际打开凭据校验或执行清除。清除后的指引记录也会重置。该步骤追加在结束前，保留原进度版本，不强制已完成或跳过的用户重新播放。

每步只突出一个主要操作区域，用半透明灰色蒙版和局部挖空展示。挖空处允许原生点击、长按、拖动；其余区域阻止误触，说明面板可滚动。

## 数据和时间隔离

指引是独立的内存练习会话，复用正式 `YOURoomApp` 和现有页面 / 弹窗 / 计算逻辑，不复制一套假界面。

- `GuideData` 仅生成虚构教室数据，无数据库、HTTP、账号或凭据存储引用。
- `GuideSettings` 仅保存内存偏好，开始时参考当前外观；练习中的主题、深色模式、标签、标记、筛选、组合和方案均不回写正式会话。
- 原工作区保持挂载，关闭指引后回到原页面，不替换其规划草稿或已生成结果。
- 唯一持久化内容是指引进度。账号标识使用设备本地随机密钥的 HMAC，不保存明文账号、密码或令牌。

示例时间固定为当天校园时区 **10:00**，练习组合为 **11:00–12:00、14:00–16:00、19:00–20:30**。

练习不是普通 `demo` 模式：保留正式过去时段校验。指定步骤把开始设为 09:00，点击加号稳定出现过去时段提示；下一步真实调用“从现在起”，开始变为 10:01，结束仍为 12:00。终止计算步骤刻意保持练习计算等待，真实停止按钮可以取消，不依赖手机速度碰巧捕捉加载状态。

## 实现位置

- `domain/UsageGuide.kt`：进度、版本、账号 / 访客作用域。
- `data/local/GuidePreferenceKeys.kt`、`SettingsStore.kt`：独立 DataStore 键及账号匿名标识。
- `ui/GuideSteps.kt`：章节、步骤、说明、目标控件。
- `ui/GuideRuntime.kt`、`data/GuideData.kt`：练习状态、固定时钟和示例数据。
- `ui/UsageGuide.kt`：生命周期、播放器、动态定位、准备状态、同窗逻辑弹层与唯一挖空蒙版。
- `YOURoomViewModel`：首次进入、重播与进度持久化；训练实例禁止再次启动指引。

筛选、教室编辑、时段菜单、模板和确认弹层保留逻辑窗口 ID，用于准确匹配高亮目标；指引中统一投放到外层 Dialog 内，保留调用处的主题、字体缩放和其他 CompositionLocal。唯一蒙版始终在全部练习弹层之上，目录再显示在蒙版之上，不再创建 / 关闭多个原生窗口或迁移蒙版。普通使用路径仍使用原生 Dialog / Popup 及原有动效。
