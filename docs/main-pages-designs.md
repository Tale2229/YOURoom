# 三个主页面 · 三版层次设计

最新微调 `1.40.26 / 142`：在 `1.40.25` 基础上将教室条目上下色面边界同步下移 10dp。顶部留白改为 14dp，时段条底部留白增加 10dp，列表标题区底部补入 10dp，保持内容位置与条目总高度不变。本次仅改代码及断言，按用户要求不运行测试，也不重新打包；下文为此前设计与验证记录。

演示入口：[main-pages-preview.html](main-pages-preview.html)。首轮仅比较 HTML 方案；正式应用在 `1.40.24 / 140` 采用 B「浅色分层」，并按确认意见微调顶部浅底、上拉提示及设置行距。

最新修正 `1.40.25 / 141`：这里的“最顶部”指列表首个收藏教室，正式列表改为从浅底开始交替。每个色面边界整体上移 24dp，角标上、右留白相等；通过转移尾部留白并压缩标题区，保留房号、角标、时段条的绝对位置及条目间距。设置页尾不再采用 B 版分区设计，恢复原来的两个居中纵向文字按钮与版本号，只保留隐藏 / 上滑显示。以下 HTML 与 `1.40.24` 记录作为设计过程留存，不代表上述修正后的完整正式样式。

## 共同边界

- 沿用正式 12 主题的浅 / 深配色快照、原生头像 WebP，以及主页面的品牌 / 校区头部与底部导航。以马蒂斯浅色作为初始比较环境。
- 教室页保留六列节次、搜索与筛选的位置，保留房号、容量、标签、备注、收藏角标及可用时段条。三版主要比较用于分隔的装饰，不以新增信息或卡片堆叠制造差别。
- 规划保留开始 / 结束时间滚轮、加号 / 期望教室 / 宽松模式 / 启动四按钮、已添加时段、方案选择条和结果。A 接近现状；B、C 只对结果分隔做小幅尝试。
- 设置项保持深色模式、时段条样式、默认校区、节次编号、教室标记、规划偏好、使用指引、关于的顺序。
- “清除缓存”及以下内容，包括退出登录和版本号，全部放在第一屏设置内容之后。第一部分至少占满整个内部滚动视口，不用覆盖层遮挡按钮。默认不可见；在手机画面内上滑、滚动或使用键盘浏览即可进入，向下滑回到主设置。不使用点击开关自动展开页尾。
- 初稿用“上滑查看本机与账户”提示隐藏区域；最终 B 版删除该文字和上尖角，只留一条 30 × 3 的短横线。清理始终使用危险操作颜色，并保留账密校验与不可恢复的文字提醒。HTML 中不进行校验、删除或退出。

## A · 留白刻度

教室条目底部的长细横线缩短为与文字左边缘对齐的 23px 刻度。分隔主要由留白完成，短线只起收尾作用；保持原有条目信息的密度与对齐。

规划基本不动。设置页尾保持与页面同色，用小节标题与内缩分隔划出“本机与账户”，清除 / 退出竖向排列，最接近现有使用习惯。

适合优先追求耐看、轻量、与当前界面连续的方向。

## B · 浅色分层

教室条目取消分隔横线，改为连续、极浅的交替色面；不加圆角盒子、不使用投影。查询标题区的浅色分区建立上部筛选与下部列表的层级。

正式微调：节次 / 搜索顶部使用主题 `surface` 浅底，“可选教室”使用 `surfaceContainerLow`，两者不混为同一色面。条目本体与左滑前景、下方可用时段条共用同一底色，收藏排序、时段提示及动作动画不变。隐藏装饰线仍保留原来的 1dp 布局高度，避免指引锚点和时段条位移。

规划输入不变，只让结果区沿用浅色分层。设置页尾整体使用主题浅色面，清除和退出并列，说明与版本在同一分区收尾。

正式设置保留原有 52dp 设置行高及全部间距，不采用原型初稿的 48px 行高。通过测量实际内容，仅补足首屏剩余的空白，让账户区从首屏之后开始；短屏和大字号不压缩设置项，仍用同一列表上滑进入。保留退出确认、清除缓存账密校验和使用指引的安全限制与定位。

适合希望比现版更有分区感，同时不增加装饰细节的方向。

## C · 纵向秩序

教室条目取消底部横线，在文字左侧留白中加入很细的竖标；收藏条目使用现有收藏色，不改变收藏顺序或新增含义不明的状态点。房号与时段条仍共用原有内容左边缘。

规划只将结果连接为轻量纵向路径，输入区域不动。设置页尾是一段主题深浅相对的色面，上部圆弧带来揭页感，与头部形成呼应；深色模式改用更深的底面，不翻转成亮色大块。没有额外的弹窗或独立抽屉状态，依旧是同一滚动页。

适合希望整体有更鲜明的设计语言，同时保持秩序清楚的方向。

## 演示操作与限制

- 顶部工具可同时切换三版页面、12 主题及明暗；各手机底部导航可独立切页。
- 设置页可上滑查看页尾、切换头像主题、切换深色 / 节次编号、展开样式与默认校区。各版状态独立，刷新即复原，不使用浏览器存储。
- 教室支持节次选择、搜索、教学楼筛选、左滑操作区、收藏、标签和备注；桌面可轻点房号展开操作区。这是 HTML 的演示便捷入口，并非新增正式功能。
- 规划滚轮可以滚动 / 点选 / 用上下键调整。可增删与编辑示例时段，切换宽松模式，启动 / 停止固定的示例反馈，展开三个示例方案；不运行真实算法，不受当天时钟影响。
- 二级窗口仅用于让主页面的示例交互完整可试，并非重新设计此前已定稿的弹窗或关于 / 指引。
- 全部头像来自本地正式资源，不加载网页图片，不访问学校服务。HTML 是设计原型，不是 Compose 的逐像素截图；沙河切换仅作布局示意，不伪造真实校舍数据。
