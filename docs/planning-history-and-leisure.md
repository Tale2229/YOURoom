# 规划历史与等待内容 · 1.41.4

## 入口与布局

- 规划页内容区左下角为历史（时钟回转），右下角为等待内容（星芒），外侧留白 8dp，不显示“歇一会儿”这类入口文字；保留 48dp 触控范围、无障碍名称和长按提示。选中后显示深色底托与反色图标；历史外层回看仍点亮历史入口，历史角标显示当前账号当天的记录数量。
- 面板占用目标时段 / 校验提示下方的空间，与当前规划结果原地切换，不增加模态窗口。关闭或再次点击入口返回规划，不修改滚轮、不覆盖当前结果、不启动计算。
- 历史、静态内容 / 游戏的正文和底部入口栏统一使用 `surfaceContainerLow`；两个面板题头统一使用 `surfaceContainerHigh`。随 12 主题及深色模式变化，不增加描边 / 卡片；恐龙眼睛的留白也采用正文底色。
- 移除原来面板里的固定状态行与返回文字，改在面板外、目标时段标注下方显示左侧滑入提示。计算时显示简短进度文字；完成后提示“计算完成”，没有候选结果时提示“本次计算已结束”，右侧“查看结果”由用户主动点击，随后回到当前方案并暂停游戏。临时时段校验与模式反馈优先，关闭后仍能查看完成通知。
- `PlanningTargetStrip` 本身测量完整的时段标注（含两行时间）及节次编号；预留提示区紧随其后，再布局下方历史 / 等待面板，不使用固定屏幕 Y 坐标或 `onGloballyPositioned` 后补高度。
- 提示区通过同次布局内的 `SubcomposeLayout` 预先测量原校验、计算与完成按钮布局，预留当前宽度 / 字号下的足够高度，即使没有提示也保留。仅实际提示参与放置、绘制和无障碍；完成提示只横向滑入，不扩高容器，不挤压已展开面板。普通方案 / 指引 / 弹窗中的原校验提示不启用这段预留。
- 展开辅助面板时，上方滚轮区最多占正文视口的 28%，仍可独立滚动，让小屏有足够空间操作；正常规划结果仍沿用原先布局。
- 使用指引期间不展示新入口，避免改变现有 43 步的开口与操作边界；本轮不修改指引步骤。
- 进入规划页时不再受 `navigation.isRunning` 门槛影响：目标页立即启用按钮，不等待弹簧滑入 / 滑出完成；离场页不可操作，`CampusFrame` 仍拦截校区切换 / 数据替换期间的误触。仅改变规划页传入的 `interactive` 条件，不改教室页、设置页的动画或生成校验。

## 历史记录

- 每次正常计算完成保存一条，包含全部候选方案、导向分组和本次默认方案；切换方案不新增记录。未找到可行方案也保存；取消、被新请求取代、参数问题和异常不保存。
- 每个账号当天两个校区合计最多 10 条，按完成时间倒序，超出删除最早记录。明确展示时间、校区、目标时段和去重后方案数量。
- 历史列表使用普通可点击行、左侧 1.5dp 细竖线与留白分隔；不再使用 TextButton，消除圆角胶囊裁切文字的问题，长时段文本按实际宽度换行。
- 选中记录即关闭历史面板，回到外层正常规划工作区：目标时段条使用该记录的完整时段与冻结课表，方案导向和教室条目复用正常结果布局，不再嵌套在历史区域内。跨校区记录先切换到对应校区，界面显示回看时间 / 校区及返回当前规划的按钮。
- 回看目标条只读；方案选择单独保存在 `PlannerUtilityState.recordOption`，不写回历史或当前计算，也不重新计算。滚轮与草稿保持原有数据；主动修改草稿或点击生成后退出回看，滚轮重复回报相同值不会误清回看。
- 当前结果与历史预览独立挂载、独立选择与滚动，打开辅助面板不清空两者；关闭回看或在完成通知中点击“查看结果”恢复当前规划。历史中的校验提示不允许修改当前草稿。
- 随应用的 DataStore 在本地保存，采用单独的 `planning.history.v1` 键。复用既有 HMAC 匿名账号标识，但必须确认本次登录身份，不能仅凭上次账号键归属历史。
- 保存冻结的目标、结果、默认导向和仅与候选方案教室相关的课表快照；不保存密码、令牌、明文账号、个人备注或整份学校响应。
- 退出登录保留当天磁盘记录，再次登录相同账号可查看；未登录或不同账号不可见。演示 / 指引只用各自内存记录，退出丢弃；系统清除缓存会一并清除历史。
- 以北京时间自然日过期。前台跨零点、重新打开和返回前台均会清理；进程未运行时不声称后台准点物理擦除，下一次运行即清理，昨日历史不可展示。跨零点完成的昨日请求不写入今日记录。
- 磁盘写入失败保留本次内存记录，并在历史面板给出提示，不弹窗打断游戏。失效或被第 11 条挤出的历史记录立即退出外层回看，恢复当前规划；不能继续展示昨日或其他账号的快照。

主要文件：

- `domain/PlanningHistory.kt`：记录结构、自然日过滤和全校区合计上限
- `data/local/PlanningHistoryCodec.kt`：带版本的完整方案序列化
- `data/local/SettingsStore.kt`：原子追加、限额和过期清理
- `ui/PlanningSession.kt`：仅在当前有效请求正常完成后发送一次保存事件
- `ui/YOURoomViewModel.kt`：身份 / 演示隔离、内存回显、顺序写入与清理

## Google Dino

- 1.41.4 改为 Chromium 官方当前精灵资源的原生适配，固定上游提交并随 APK 包含 BSD 许可。角色、大小仙人掌、云、飞鸟、像素记分、GAME OVER / 重开图案与凹凸地面均来自原作，运行时无网页、网络下载或额外游戏依赖。来源及改造边界见[当前移植记录](chromium-dino-port.md)，旧 [DinoCompose 记录](dinocompose-port.md) 仅作历史说明。
- 点击起跑 / 跳跃，支持空格和方向上键；随时间加速，后期加入飞鸟。碰撞结束显示失败姿态，短暂保护后点击重来。显示五位本局分数及仅内存的本会话 HI，无永久最高分、成长、解锁、签到或排行榜。
- 切换辅助面板、离开规划页、切到后台都会暂停；由用户点击继续，不在回到页面时突然推进。
- 远景云朵以低速滚动，官方凹凸地面随实际累计路程推进；两帧恐龙落地跑动、跳起定帧，按速度加入成组仙人掌与飞鸟。角色与障碍底部比远处地平线稍低；绘制与碰撞使用统一世界坐标，场景按可用宽高缩放以容纳完整跳跃弧线。暂停后继续只恢复原来的运动，不另加跳跃速度。
- 游戏状态归规划工作区持有，普通切页 / 切面板 / 切校区不会因计算结果更新而重置。当前进程内保留一局；退出工作区、结束演示或进程重建不保证恢复。
- 计算完成只更新面板上方预留区的滑入提示及“查看结果”按钮，不自动关闭、不抢焦点、不播放声音或震动；提示高度已在展开面板前预留，不会插入新行改变场地高度。用户主动查看结果时暂停本局；回来可继续。
