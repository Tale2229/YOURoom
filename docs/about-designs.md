## 正式应用 · 1.40.21 / 137

本轮只修改正式代码，不同步历史 HTML：封面最小高度从 240dp 减至 176dp，缩短标题 / 版本 / 介绍之间的间距，链接行与说明段落、落款均收紧上下留白，正文仍为 12sp。04 不再使用独立底色；03 / 04 及落款前的分隔线左右内缩 24dp。极小屏或放大字体时继续允许滚动，不裁切正文或隐藏关闭按钮。

小猪改用 `AboutPigInteraction` 的本页专属 FIFO 队列，所有点击逐次播放。每次抖动仍为 280ms、幅度 4dp，间隔仅 16ms；眯眼状态只由队列消费者控制，不再作为动画协程的重启键。播放结束保证恢复，关闭页面取消剩余点击，不影响下次打开或个人数据。

验证：654 项单元测试、10 项关于页设备测试通过。常规字号下约 411dp / 360dp 屏宽均无需滚动即可查看全文；大字号保留滚动。覆盖同底色像素、内缩分隔线、12 主题明暗原色、队列 100 次点击和设备端 8 次快速点击逐次播放 / 复原、关闭重开、浏览器失败与返回。已查看一屏排版及眯眼截图，正式 APK 为 `com.example.youroom / 1.40.21 / 137`；未操作用户手机、账号或学校服务，未运行全量设备测试或 Lint。

### 1.40.20 小猪互动与指引顺序

小猪增加点击互动：4dp 幅度、280ms 的衰减左右抖动，与满三个时段时的加号节奏一致；动画期间使用本地 `drawable/about_pig_squint.xml`，只将两只豆豆眼替换为“><”眯眼，保留其余路径和原色。动画中重复点击不叠加，结束 / 关闭页面后恢复。指引第 40 步改为仅高亮“关于”一行且禁用进入，第 39 步为“使用指引”，不再展示关于弹窗。

验证：651 项单元测试、22 项关于 / 目录 / 指引专项设备测试通过，包含动画左右位移、表情切换与恢复、重复点击、12 主题明暗原色、全部 43 步定位及逐步遍历、大字号和进度迁移；已核对原生截图。正式 APK 为 `com.example.youroom / 1.40.20 / 136`，未操作用户手机、账号或学校服务，未运行全量设备测试或 Lint。

### 1.40.19 页面实装

## 三版结构

| 方案 | 布局 | 侧重点 |
| --- | --- | --- |
| A · 扉页档案 | 深色品牌扉页、浅色介绍、纵向编号链接、两组说明、开发者落款 | 与当前指引扉页最接近，阅读秩序明确 |
| B · 分色编目 | 浅色品牌区、两个并列链接色面、浅底数据说明、深底本地说明 | 连续分区与深浅对照最鲜明 |
| C · 路径手记 | 浅色品牌区、错落编号与连续曲线路径、深色落款 | 继承目录的导览感，串联长短不同的说明区 |

默认马蒂斯、浅色、完整展开，允许页面自然增高，不为指引中的可用高度压缩内容。可切换全部 12 个主题、明暗模式、标准 / 1.3 倍字号、完整展开 / 手机窗口，以及单版查看 / 三版对比。

## 内容与边界

- 正式文案来自 `AboutContent.kt`，预览版本使用当前构建版本 `1.40.18`。
- 保留“北邮空闲教室查询与自习规划”“非学校官方应用”、GitHub、问题反馈、数据与使用、本地与登录，以及开发者“23级 软工 小嚎猪”。
- 数据来源、现场开放、本地保存与系统备份、退出后保留账号密码 / 标记 / 设置、联网校验后清除全部本地数据 / 关闭应用 / 重置指引等说明均保留原意。
- 不添加未知联系方式、二维码、许可证或应用尚未实现的功能。
- 标识复用 `docs/branding/g66.svg` 的轮廓，作为随主题变化的单色图形内嵌到 HTML；不修改原 SVG。
- 配色复用已确认目录预览中由正式 `Theme.kt` / `ThemeRoles.kt` 提取的 12 主题明暗色板。正文与底色进行对比度校准，不引入无关颜色。
- GitHub 与 Issues 链接只在点击时打开新标签页，不自动联网；关闭 / 重新打开、主题选择和页内导航只影响当前预览，不使用本地存储。
